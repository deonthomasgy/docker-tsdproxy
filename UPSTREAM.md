# Upstream provenance

This is an independently maintained security build of
[Paulo Almeida's TSDProxy](https://github.com/almeidapaulopt/tsdproxy).
The original MIT license and copyright notices are retained.

Imported tag: `v3.0.0-beta.4` (2026-09-30). The upstream Go module path is
retained to avoid rewriting imports. The upstream release, documentation,
Homebrew and AUR publishing workflows have been replaced by verification
on our `main` branch. Publishing uses the tested local build described in
`SECURITY-BUILD.md`; CI does not need registry credentials.

3.x is currently a beta release. See `MIGRATION.md` before deploying from 1.x.
